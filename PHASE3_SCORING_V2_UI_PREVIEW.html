3 score states side-by-side. Every "NEW v2" element shown is backed by real fields already in the merged data.json — nothing here is fake. ~2h to wire into actual Hero component.

What's new in each card (highlighted blue)

  • Regime + spot row — small panel under main score showing EWMA-smoothed regime vs current spot value. Tells the user "is this a sudden move or a sustained trend?"
  • Triple-jeopardy chip — pulses red when oil + macro + flows all simultaneously ≥ 65. Single most actionable risk signal.
  • Shock indicator — appears only when |point_move_30d| ≥ 8. Shows direction + magnitude.
  • Score state warning — amber banner when ≥30% of drivers are stale/missing. Replaces silent "neutral 50" default.
  • Reference events strip — historical anchors (Lehman 70, taper 63, COVID 60, oil-shock 67, election 49) so users know where 51 sits.
  • Correlation adjustment row — small note showing the haircut applied (raw avg → final), explains why drivers can be elevated without IRS spiking.
  • Driver feeder breakdown — existing tiles, but with new score_state badges (e.g. "insufficient_data").
