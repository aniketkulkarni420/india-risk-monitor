IRM redesign · brutal audit + 3 versions

Dashboards are digital control rooms, not magazines. Current IRM violates the principles enough that the home view actively works against the user's primary need: "is anything wrong right now?"

What's wrong (15 specific violations)

  1. Scrolling is mandatory — critical metrics live below the fold. Single most-violated principle.
  2. Hero has 5+ competing elements — IRS + 6 tiles + timeline + chips + reference events. 50ms window blown.
  3. 3 different section layouts — V60 Flows ≠ Cluster Real Econ ≠ Ranked Sectors. No muscle memory.
  4. 4 status levels × N color tints — color is decoration here, not a tool.
  5. No "what changed today" — user must mentally diff yesterday vs today.
  6. 70 visible data points — the 3–7 rule is broken by 10×.
  7. Sparklines without labels — pure decoration, not informative.
  8. No personalization — Hormuz analyst = FII analyst = retail subscriber. Same screen.
  9. ★ watchlist exists but isn't surfaced as a primary view.
  10. No actions/recommendations — risk dashboards exist to inform decisions; we inform about decisions.
  11. No sidebar — top tab nav burns vertical real estate that should hold KPIs.
  12. No breadcrumbs on inline expand — user gets lost in drill-down.
  13. Inconsistent grid — sections drift off the 4pt/8pt baseline.
  14. Reference events buried — the "is this normal?" anchor should frame the score, not sit below it.
  15. Drill-down kills overview — inline expand replaces context; only one metric in mind at a time.
Root cause: the IRM was built bottom-up (parsers → metrics → sections → hero). The design report explicitly says: design the dashboard last. We're feeling the cost — the home view is a sum of components, not a designed summary. Scoring v2 (triple-jeopardy, regime/shock, reference events) added value but added more elements to render = more cognitive load.

Recommendation

Ship V2 (Pulse Brief) as the new home page. It's the highest signal-to-cognitive-load ratio of the three, the cheapest build, and the only version that answers all three primary questions ("am I OK / what changed / what's elevated") in the first 5 seconds. The pulse line is the single most-information-dense element across the three versions — it does the work of the current Hero's 5 competing elements.

Add V1 (Control Room) as a "Compact" toggle. Power users who already know the system will prefer the terminal-tight version. One CSS class swap; same data layer; minimal extra work.

Treat V3 (Personalized Watch) as Phase 4 / paid tier. Highest user value but requires auth, a state model, and an "action engine" that converts metric states into ACT/WATCH/HOLD guidance. That's a 3–4 week build — not a redesign, a product expansion. Worth doing once V2 ships and the basics are correct.

What this means for build order: the redesign isn't a "Phase 3 UI" task — it's a re-architecture of the home page. The 9 metric-section refinements in the Phase 3 picker (Sectors 4D grid, Macro toggle, etc.) become drill-down views, not home-page elements. That actually simplifies the Phase 3 picker.
