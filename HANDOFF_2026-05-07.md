## Trend layer per section · what to add (Combo 2 smart application)

**Locked principle:** the section trend strip is one tool among several. It belongs where you have multiple metrics in a flat list. It's WRONG where the section already has a temporal viz, has 1 hero metric, is comparison-shaped, or is itself a list.

| Section | Trend tool | Why this · why not strip |
|---|---|---|
| Hero | 30-day score sparkline behind value · banded zones · 30d range chip | Single metric — strip would have 1 row = wasted format |
| Flows | Tiny sparkline in each lens (50×16, top-right) · composite pill on each lens · period-tab labels carry headline net | Comparison-shaped — each lens is a different angle, per-lens spark fits |
| **Macro** ★ | **Canonical section trend strip · 5 metrics × 30d heatmap** + composite pill on cards | Macro IS a list of dimensions — strip shows synchronicity ("inflation cooling while FX firms") |
| Real Economy | Composite pill on cluster cards · **NO section strip** (would dilute Auto bar trio) | Auto bar trio is the centerpiece, strip would compete |
| Freight | Nothing (Stress Map v2 already has 7-day trails) | Map IS the trend layer — adding strip duplicates |
| Market | 30-day path overlay on PE band (faded dot trail) | Same chart, two layers — "PE journey" |
| Sectors | Per-row rank-change arrow + 5d sparkline | List IS the dashboard — trend in rank movement |
| 24h feed | Streak chip on chained events | Already trend-aware by design |
