## UPDATE · 2026-05-11 late · root-cause analysis + first-principles solutions

### Why bugs persist after fixing parsers individually

We're scraping HTML with regex. That's the root cause. Five failure modes documented:

| # | Failure | Why regex can't solve |
|---|---|---|
| 1 | URL changes (IHMCL, GST docs both 404'd) | Pages die · we follow them |
| 2 | SPA / JS-rendered pages (NPCI · NSE · DGCA) | fetch() returns empty shell · regex matches nothing |
| 3 | Geo-blocking · some India govt sites | CI runs in US/EU · gets 403 |
| 4 | News page format churn | Body HTML changes weekly |
| 5 | Registry mapping gaps (wacr_repo_spread) | One-line config fix per gap |

### First-principles solutions (NOT YET IMPLEMENTED · next-session work)

**P0 · Headless browser parser** (~3h · highest ROI)
- New `scripts/ingest/parsers/playwright_render_v1.mjs`
- Uses Playwright (already installed for visual audits · zero new deps)
- Solves all SPA failures in one parser: NPCI, NSE, DGCA, NSDL portal
- Pattern: launch chromium → page.goto(url) → page.waitForSelector(target) → page.textContent → regex
- Fixes ~5 currently-red metrics

**P1 · Manual override layer** (~30 min)
- `data/manual-overrides/{metric_id}.json` with `{value, as_of, source_url, expires_at}`
- Read with HIGHEST priority in ingest.mjs · before any parser
- For slow-moving data (monthly GST/CPI), Aniket gets auto-issue → updates one file in 60 sec → system uses that until next official ingest succeeds
- Eliminates "waiting for parser fix" downtime

**P2 · Aggregator-first fallback ordering** (~1h)
- Re-order all parser URL lists to put TE / Yahoo / Investing BEFORE primary govt sources
- Aggregators are battle-tested at scale · primary sources break weekly
- ~30 min freshness loss · massive reliability gain
- Apply to: upi_value, eway_bills, fastag_toll, rail_freight, all macro metrics

**P3 · RSS / article-title parser** (~2h)
- New `scripts/ingest/parsers/news_rss_v1.mjs`
- Parses Business Standard / ET / Mint / Reuters India RSS feeds
- Extracts numbers from article TITLES (stable format) not body HTML (churn)
- "UPI hits ₹24.85 L Cr in April 2026" → captures 24.85
- Robust across page redesigns

**P4 · Cross-source verification** (~2h)
