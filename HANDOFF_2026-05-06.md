## Open bug · ship next session FIRST

### India Risk Score section getting cut on the right side

User flagged this in the final message of the previous session. The mobile hero card's score row overflows the right edge.

**Suspected root cause** (in priority order — verify with viewport inspection):

1. **`.hv-score-row` flex layout overflow on ≤390px viewports**
   - Row contains: `.hv-score-big` (56px font "76") + `.hv-score-sub` (/100) + `.hv-spark-inline` (140px SVG) + `.pill` (right-aligned via margin-left:auto)
   - 56 + 14 + 140 + ~70 + gaps ≈ 320-340px content width
   - 360px viewport - 40px hero-card padding (20×2) = 320px available
   - Status pill or sparkline overflows on narrowest devices

2. **`.hv-narrative` italic line** doesn't have `word-break` set; long inline values like driver labels can run off the right edge

3. **`.hv-attribution` "Today's movers: ..."** is a `display: flex` row with `flex-wrap: wrap` but the inner spans don't `min-width: 0` — long sector names + numbers extend right

4. **`.hero-condensed-lead`** when collapsed concatenates 3 facts with `·` — could exceed mobile width without wrap

**Recommended fix shape (don't blindly apply, test first)**:

```css
@media (max-width: 600px) {
  .hv-score-row {
    flex-wrap: wrap;
    align-items: center;
    gap: 8px 14px;
    /* score on its own row, sparkline + pill below */
  }
  .hv-spark-inline {
    width: 100%;
    max-width: 100%;
    margin-left: 0;
    height: 36px;
  }
  .hv-narrative,
  .hv-attribution,
  .hero-condensed-lead {
    word-break: break-word;
    overflow-wrap: anywhere;
  }
  .hv-attribution {
    flex-direction: column;
    align-items: flex-start;
    gap: 4px;
  }
}
```

Verify at 360, 390, 430 px viewports specifically.

### Other categories of bugs to inspect

1. **Z-index / stacking order**
   - Bottom tab bar z-index: 100
   - Cmd-K palette backdrop z-index: 100
   - Drawer backdrop z-index: 100, drawer z-index: 101
   - Cmd-K and bottom tab might overlap

2. **Safe area insets**
   - Verified bottom-tab-bar has `env(safe-area-inset-bottom)`. iPhone notch/dynamic island NOT explicitly handled at top — may interfere with sticky topbar.

3. **Touch event leaks**
   - Drag-to-close handler on drawer: ensure removing listeners on close
   - Bottom tab bar buttons: hover styles unwanted on touch (use `@media (hover: hover)` guard)

4. **Color contrast on light backgrounds**
   - `--ink-3` is now `#8590a3`. On `--surface` (`#0f1319`), contrast ~4.1:1.
   - Check on hero-card surface, matrix-cell #0e1218.
   - Sub-text against accent-soft bg may fail.

5. **Empty states**
   - Card-based metric mode on mobile: when sparkline shows "verifying badge" inside a card, layout might break.
   - Today bullets when 0 metrics qualify: hero would show empty Today section.

6. **Localization / number formats**
   - Indian numbering uses lakh / crore. Currently using `Intl.NumberFormat('en-IN')`.
   - Some places hard-code ₹/$ symbols. Spot-check large values.

7. **Tab bar interaction with hash URLs**
   - Bottom tab bar onclick calls `setActiveTab(tabId)` — same as top. Should work but verify hashchange listener still fires correctly.

8. **Hero collapse state across page reload**
   - localStorage.irm.heroCollapsed persists. First-time visitors get collapsed default. Check if this is desired behavior or if it should default to expanded.

9. **Bottom sheet drag on iOS Safari**
   - `touchstart` on drawer top 60px is correct, but iOS Safari's pull-to-refresh gesture conflicts with drag-down. May need `touch-action: pan-x` or similar.

10. **Section visibility CSS rule on hashchange**
    - When user changes hash via cmd-K or tab click, `body[data-active-tab=...]` updates. Verify all section-frames hide/show correctly.

### Tier 3 · Native gestures (do after fixing the right-side-cut bug)

**G · Pull-to-refresh**
- Standard mobile gesture
- Triggers re-fetch of `data.json` + re-render
- Visual: spinner sliding down + success toast
- ~30 lines JS, ~50 lines CSS
- Detect at top of page only · use `touchmove` delta threshold

**H · Swipe between tabs**
- Left/right swipe on body content switches to next/previous tab
- Industry standard (Twitter, Instagram, Slack)
- Touchstart/move/end listeners on body
- Translate body during drag, snap on release
- Falls back gracefully (tap still works)

**I · Persistent risk-score ticker**
- After scrolling past the hero, a thin (28px) sticky bar at top:
  ```
  India Risk 76 · HIGH · 3 shocks
  ```
- Tap to scroll back to full hero
- Like Bloomberg's mobile ticker
- IntersectionObserver on hero-card determines visibility
- Show: when hero out of viewport AND on mobile

### Tier 4 · Polish + feel

**J · Skeleton loaders**
- Each metric row shows shimmer placeholder while `data.json` loads
- ~40 lines CSS animation
- Use `@keyframes shimmer` with linear-gradient
- Apply to `.metric-table tr.tr-loading` (already exists, just unused)

**K · Haptic feedback**

- `navigator.vibrate(15)` for soft, `navigator.vibrate([20, 10, 20])` for medium

**L · Outdoor / light mode toggle**
- Add sun icon next to cmd-K
- `[data-theme="light"]` overrides on `<html>`
